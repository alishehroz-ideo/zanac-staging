# Zanac — WebGL staging build (GameBull)

Staging deploy of the Zanac WebGL build, served via GitHub Pages.

- **Play:** https://alishehroz-ideo.github.io/zanac-staging/
- Unity 6000.4.3f1 · WebGL · IdeofuzionBridge template
- Brotli compressed (`.unityweb`) with Unity's JS decompression fallback,
  so it works on GitHub Pages without `Content-Encoding` headers.
- GameBull lobby canvas in `Zanac_Title`; gameplay in `Zanac_Game`.
- Score submission + game-end panel via `GameBullZanacBridge`.

Generated by `Tools > Zanac > Build WebGL (stagingbuild)`.
